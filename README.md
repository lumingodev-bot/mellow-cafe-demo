# Mellow Café Demo

A responsive, mobile-first website for a café in Lusaka, Zambia. This is a demo project showing what I build for local small businesses.

**Live site:** https://mellow-cafe-demo.netlify.app

## Features

- Tabbed menu (coffee and drinks, bakes, brunch) with prices in kwacha
- Table booking form that sends the details to the café on WhatsApp
- Click-to-call and Google Maps directions links
- Opening hours and an "Our story" section
- Mobile-friendly layout with fast load times

## Built with

- HTML5
- CSS3
- JavaScript (vanilla)
- Hosted on Netlify

## Running locally

1. Clone the repo
2. Open `index.html` in your browser
